# Local SEO Audit Checklist

40-point audit for any local business. Walk through it top-to-bottom. Anything unchecked is an opportunity.

---

## Google Business Profile

- [ ] 1. Profile exists and is claimed (verified)
- [ ] 2. Business name is exact legal/trading name (no keyword stuffing)
- [ ] 3. Primary category is the most specific accurate option
- [ ] 4. All relevant secondary categories added (up to 9)
- [ ] 5. Address is accurate and matches website/other listings exactly
- [ ] 6. Service areas defined (if service-area business)
- [ ] 7. Phone number is local (country code + same as website)
- [ ] 8. Website URL points to canonical homepage
- [ ] 9. Hours are accurate, including holidays
- [ ] 10. Attributes filled (accessibility, amenities, etc.)
- [ ] 11. Business description uses primary keywords naturally, 500–750 chars
- [ ] 12. Services section has individual services with descriptions + prices
- [ ] 13. At least 10 high-quality photos uploaded
- [ ] 14. Logo and cover photo set
- [ ] 15. Q&A has at least 5 seeded questions with answers
- [ ] 16. Google Posts published at least monthly
- [ ] 17. Appointment / booking link added (if applicable)
- [ ] 18. Messaging enabled and responded to within 24h

## NAP consistency

- [ ] 19. NAP identical on: website, GBP, Facebook, Instagram, LinkedIn
- [ ] 20. NAP identical across top 5 country-specific directories
- [ ] 21. NAP identical across top 3 industry-specific directories
- [ ] 22. `LocalBusiness` schema on homepage with NAP
- [ ] 23. No duplicate GBP listings for the same business

## Reviews

- [ ] 24. Minimum 20 Google reviews
- [ ] 25. Average rating between 4.2 and 4.9
- [ ] 26. At least 3 new reviews in the last 90 days
- [ ] 27. Every review responded to (positive and negative)
- [ ] 28. Review acquisition process in place (QR code, follow-up email, link)
- [ ] 29. No reviews incentivized / bought / fake

## Website — local signals

- [ ] 30. Homepage title includes primary service + city
- [ ] 31. Homepage meta description includes primary service + city
- [ ] 32. Main H1 includes primary service + city naturally
- [ ] 33. NAP visible in footer on every page
- [ ] 34. Dedicated Contact page with map embed + hours
- [ ] 35. Each core service has its own page (not lumped into one)
- [ ] 36. If multi-location: dedicated landing page per city with unique content
- [ ] 37. Mobile-friendly (passes Google Mobile-Friendly Test)
- [ ] 38. Page speed: Core Web Vitals passing

## Citations & links

- [ ] 39. Listed in top 10 country-specific directories
- [ ] 40. At least 1 backlink from a local source (newspaper, blog, partner, association)

---

## Score interpretation

- **35+ checked**: Strong local SEO; focus on content and links for growth
- **25–34 checked**: Average; multiple concrete fixes available
- **15–24 checked**: Weak; prioritize GBP completeness and reviews first
- **Under 15**: Critical gaps; treat GBP as a 2-week project before doing anything else

## Priority order for fixes (if starting from scratch)

1. Claim and complete GBP (#1–18) — highest impact, fastest wins
2. Get reviews flowing (#24–29) — compounds over time, start ASAP
3. Fix NAP consistency (#19–23) — easy win, often overlooked
4. Website local signals (#30–38) — requires dev work but foundational
5. Citations and links (#39–40) — lowest priority per unit of effort, but meaningful in aggregate
